# S3D release preparation — 14 October 2026

Scope follows the shared workspace feature briefs `docs/features/s3d-database-builder-reference.md`
and `docs/features/smartplant-three-pillar-analysis-plan.md`, preserving existing behavior
under decision I-06. Shared context lives outside this repository.

This release adds the S3D upload-to-preview flow, recovery of processing jobs from the
route, explicit extraction save and run history, plus workbook review/editing updates.
Uploads ask the backend to resolve owner-scoped project folders using SHA-256 identity.
Existing header/sidebar and legacy extraction tools retain their established ownership.
Release validation found and corrected stale create-before-upload wiring and missing
History Logs navigation in `S3DExtractionFlow.jsx`, aligning the existing components
with the approved file-identity/save-history contract. Browser startup timeout is
optionally configurable through `S3D_TEST_TIMEOUT_MS` (default remains 90 seconds).
The pending workbook renderer also lacked its virtual-row configuration and
crashed on preview; explicit viewport limits and overscan now supply that configuration.

Remote development was fetched and fast-forwarded from f84922b to e87b215 before
restoring local changes without conflicts. Remote contextual Help updates remain.

Changed-source ESLint passed with zero errors and 135 warnings. Browser validation
must use a dedicated Vite port: the existing local port 5173 serves an older app.
The initial build exposed an incomplete local dependency installation (`iobuffer`
missing despite being locked); `npm ci --ignore-scripts` restored the committed
dependency graph without manifest or lockfile changes.

All nine S3D Playwright browser tests passed against this checkout on port 5187
with synthetic API fixtures, `S3D_TEST_TIMEOUT_MS=240000`, native filesystem
watching and dependency scanning restricted to the fixture entry. Rechecking the
modified flow/canvas returned zero lint errors (12 warnings). Browser checks cover
folder selection, upload retry, failed processing, mobile shell, resumed jobs,
explicit save, retained history after refresh and retry after save failure.
The final production/PWA build passed after all source fixes, generating 125
precache entries; existing chunk-size and Browserslist-age warnings remain.

The full top-level Node regression suite ran 502 tests: 498 passed and four
failed in unchanged Sales code/tests. Failures concern document lineage and
classification labels (`sales-document-control.test.js`), MSG encoding
(`sales-office-documents.test.js`) and the EIO label
(`sales-opportunity-register.test.js`). Git comparison against origin/development
confirmed these tests and their Sales source files are unchanged by this release.

Backend migration 0012 must precede the new save UI. It was applied and physically
verified on local PostgreSQL on 14 October 2026; production remains unverified.
Saving extracted data does not approve engineering content or certify SmartPlant import.
